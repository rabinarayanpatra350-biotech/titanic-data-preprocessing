# Titanic Dataset — Cleaning & Preprocessing Pipeline (Python)

**Week 1 Task: Python for Machine Learning & Data Preprocessing** — internship project by Rabi Narayan Patra

This project cleans and preprocesses the classic **Titanic dataset** (891 passengers × 12 columns) using Python, pandas, and NumPy — documenting every preprocessing step in code, console output, charts, and a written report.

## What the pipeline does

| Step | Action | Key result |
|------|--------|------------|
| 1 | Data loading & initial inspection | 891 × 12; dtypes, statistics, missing-value audit |
| 2 | Exploratory data analysis (EDA) | Survival 38.4% overall; 74.2% (women) vs 18.9% (men); by class 63/47/24% |
| 3 | Handling missing values | `Cabin` dropped (77.1% missing); `Age` imputed with (Sex, Pclass) group medians; `Embarked` imputed with mode |
| 4 | Data cleaning | 0 duplicates; category dtypes; fare outliers retained (real first-class fares) |
| 5 | Feature engineering & selection | `Title` extracted from Name; `FamilySize`, `IsAlone`; dropped PassengerId/Name/Ticket |
| 6 | Encoding categorical variables | `Sex` → binary; `Embarked` + `Title` → one-hot (8 dummy columns) |
| 7 | Normalization | Min-max scaling of `Age` and `Fare` to [0, 1] |
| 8 | Verification | Final: 891 × 17, 0 missing, all numeric; logistic regression CV accuracy **82.2% ± 2.3%** |

## Results at a glance

From the actual run (see `run_log.txt`):

- Raw dataset: 891 × 12, with 866 missing values across 3 columns
- Final dataset: **891 × 17 — fully numeric, 0 missing values**
- Baseline model-readiness: **82.2% ± 2.3% cross-validated accuracy** (5-fold logistic regression)

## How to run

```bash
pip install -r requirements.txt
python preprocess.py
```

Place `titanic.csv` in the same folder as the script — download it from [Release v1.0](https://github.com/rabinarayanpatra350-biotech/titanic-data-preprocessing/releases/tag/v1.0) (or the original source below). Running the script reproduces every number and chart in this project, and writes:

- `cleaned_titanic.csv` — the model-ready dataset
- `figures/` — the five PNG charts
